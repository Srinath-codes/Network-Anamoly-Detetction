EnsembleGuard

Project Objective: To provide a robust, AI-powered layer of defense against modern network threats. EnsembleGuard leverages high-performance machine learning to monitor, detect, and classify anomalies in real-time, ensuring system integrity and data security.

Using an ensemble of Random Forest, XGBoost, LightGBM, and CatBoost, we detect malicious traffic with 99%+ accuracy.

Denial of Service. Overloading a system to make it crash or unavailable.

Network scanning to find active ports or system vulnerabilities.
